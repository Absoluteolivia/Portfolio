SwiftLink System Architecture

System Problem & Solution

Problem: Standard URL shortening requires low-latency URL redirection while handling analytics data ingestion and protecting the system against high-frequency API abuse.

Solution: Implemented an Express.js API gateway with a Redis cache-aside pattern. Frequently accessed shortened keys hit Redis directly in sub-milliseconds, bypassing database disk reads.
